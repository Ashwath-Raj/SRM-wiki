# Security Gate

Inspect:
- authentication
- authorization
- object-level access control
- input validation
- injection
- XSS
- SSRF
- IDOR
- path traversal
- uploads
- secrets
- unsafe deserialization
- dependency risks

Produce:
- finding
- evidence
- impact
- remediation
- verification

Never declare software "secure"; report remaining risks.
